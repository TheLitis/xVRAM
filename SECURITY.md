# Security policy

## Supported versions

xVRAM has not released a supported production version. Security fixes currently target
the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for the repository instead of a
public issue. Include the affected revision, environment, reproduction steps, impact,
and whether GPU device loss or host memory corruption is involved.

Do not attach reports containing secrets or unrelated machine identifiers. Capability
reports include hardware and operating-system metadata and should be reviewed before
public sharing.
